# Исходники журнала «Ателье»

Одна статья — один файл `NN-slug.md`. После правки: `python3 journal/_build.py` из корня репозитория.

Шапка (между `---`): `slug`, `rubric` (volosy · kosmetologiya · uhod · moda · lyudi), `order` (порядок на обложке, 1 — главная история),
`format`, `title` (курсив в `*звёздочках*` — красным), `dek`, `description`, `seo_title`, `cover` (файл из `journal/media/`),
`cover_alt`, `cover_caption`, `cover_fit: contain` (для кадров кампании — без обрезки), `date`, `updated`, `author`, `reviewer`,
`medical: yes` (добавит предупреждение о противопоказаниях), `related` (slug через запятую).

Текст: `## Вопрос` → H2 и пункт оглавления; `- ` списки; `> цитата` + `> — автор`;
`!img файл | alt | подпись | wide|contain`; `!video путь.mp4 | постер | подпись`;
блоки `::: kratko`, `::: my Заголовок` (ссылки строкой `[текст](url)` станут кнопками), `::: faq` (строки `Q:` / `A:`),
`::: table Подпись` (строки `| a | b |`), `::: sources`. Каждый блок закрывается строкой `:::`.

Правила бренда: только «клиент»; без «лучший/№1»; фото кампаний без текста поверх и без обрезки; медтексты проверяет врач.
